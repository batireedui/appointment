# Тайван эмнэлэг — Цаг захиалгын систем

PHP + MySQL + HTML/CSS/JS дээр бүтээсэн эмнэлгийн цаг захиалгын систем.
Өвчтөн онлайнаар цаг захиалж, админ бүх зүйлийг удирдана.

## Байршуулах

1. **Өгөгдлийн сан үүсгэх**
   `sql/schema.sql`-ыг MySQL/MariaDB дээрээ ажиллуулна (жишээ нь phpMyAdmin эсвэл):
   ```
   mysql --default-character-set=utf8mb4 -u root -p < sql/schema.sql
   ```
   Энэ нь `hospital_appointment` санг үүсгэж, хүснэгтүүд болон жишээ өгөгдлийг (эмч, үйлчилгээ) хийж өгнө.
   `--default-character-set=utf8mb4` заавал ашиглана уу — эс бөгөөс кирилл үсэг (эмчийн нэр гэх мэт) буруу кодлогдож болзошгүй. phpMyAdmin ашиглаж байгаа бол "Import" цонхны кодчиллыг utf-8 болгосон эсэхийг шалгана уу.

2. **Холболтын тохиргоо**
   `config/database.php` дотор өөрийн серверийн мэдээллийг оруулна:
   ```php
   define('DB_HOST', 'localhost');
   define('DB_NAME', 'hospital_appointment');
   define('DB_USER', 'root');
   define('DB_PASS', 'таны нууц үг');
   ```

3. **Файлуудыг хостинг руу байршуулах**
   Бүх агуулгыг (index.php зэрэг) веб серверийнхээ document root-д хуулна (жишээ нь `htdocs/`, `www/`, эсвэл `public_html/`).

4. **Нэвтрэх мэдээлэл**
   - Ажилтны (админ) панель: `/admin/login.php`
     - Нэвтрэх нэр: `admin`
     - Нууц үг: `admin123`
   - Өвчтөн бол `/register.php`-ээр шинээр бүртгүүлнэ.

   ⚠️ Ашиглалтад оруулахын өмнө админы нууц үгээ **заавал солино уу** (Admin → Патиентс хэсэгт биш, шууд users хүснэгтэд password_hash-аа `password_hash()`-ээр дахин үүсгэж солино).

## Файлын бүтэц

```
config/database.php        — DB холболт
includes/functions.php     — Нийтлэг функцууд (auth, боломжит цаг тооцоолол г.м)
includes/header.php, footer.php — Нийтийн хуудсуудын layout
assets/css/style.css       — Дизайн
assets/js/booking.js       — 4 алхамт захиалгын урсгал (AJAX)

index.php, services.php, doctors.php   — Нийтэд харагдах хуудсууд
register.php, login.php, logout.php    — Өвчтөний бүртгэл/нэвтрэлт
book.php + ajax/get_slots.php, ajax/book.php  — Цаг захиалах урсгал
my-appointments.php, cancel.php        — Өвчтөний өөрийн захиалгууд

admin/                      — Админ панель (эмч, үйлчилгээ, хуваарь, захиалга, өвчтөн удирдлага)
sql/schema.sql              — DB бүтэц + жишээ өгөгдөл
```

## Онцлог

- Эмч тус бүрийн долоо хоногийн хуваарь + онцгой амралт/нэмэлт цагийг харгалзан боломжит цагийг тооцоолж, давхар захиалгаас сервер талд хамгаалалттай (unique constraint + давхар шалгалт).
- Эмч тус бүрийн үйлчилгээний онцгой үнэ тохируулах боломжтой (эсвэл үндсэн үнийг ашиглана).
- Бүх нууц үг bcrypt-ээр хадгалагдана (`password_hash`/`password_verify`).
- Бүх өгөгдлийн сангийн хүсэлт prepared statement ашигладаг тул SQL injection-оос хамгаалагдсан.

## Туршилт

Систем бүрэн туршигдсан: бүртгэл → нэвтрэлт → 4 алхамт цаг захиалга → давхар захиалга хориглох → админ талаас эмч/үйлчилгээ/хуваарь нэмэх → захиалгын төлөв өөрчлөх → өвчтөн цуцлах — бүгд зөв ажиллаж байгааг MySQL/PHP орчинд шууд шалгасан.
